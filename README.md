# Let's Surf

Surf game from Microsoft Edge extracted and modified to be usable in other browsers.

NOTE: This repository contains the previous version of edge surf. 

## Project Structure

- `extracted` - Original game files extracted from Edge 122.0.2365.106, from a fresh installation of Windows 11 24H2 (Build 26100.1742)
- `fixed` - Game files modified to work without `chrome.send`
- `mod` - Partially deobfuscated version with various patches
